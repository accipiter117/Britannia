# IMPLEMENTATION GUARDRAILS

Population is not currency; recruitment reduces workforce.

Upkeep = affordability.
Supply = operational access.

Political control can change quickly; culture changes slowly.

Conquest is fast; governance is slow.

Winter creates planning pressure, not arbitrary mass death.

Armies do not automatically fight merely because they are adjacent.

AI does not cheat and acts once per season.

Roman invasion is pressure, not predetermined defeat.

Victory should not be a forced percentage ending.

Art must not be required for simulation.

Prototype dates use Year/Season only.

All numbers are provisional balance values.
