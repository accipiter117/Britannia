# UI / UX

Map-first. Most play happens on the map.

## Permanent HUD
Faction, Population, Food, Timber, Materials, Wealth, Season/Year, critical warning.
Persistent END SEASON.

## Contextual panels
District: population, production, buildings, control, culture, loyalty, prosperity, construction, actions.
Army: strength, formations, morale, supply, experience, commander, movement, actions.
Faction: relationship, military strength, known territory, diplomacy, trade, war/peace.
Event: problem, consequences, choices, deadline if relevant.

## Build
Show valid options. Grey out unavailable options with a reason.

## Notifications
Red Critical: starvation, attack, imminent rebellion.
Amber Important: construction complete, trade disrupted, army recovered.
Grey Information: season change, minor faction founded.
Notifications should jump to relevant location.

## Mobile
Tap select.
Tap selected = drawer.
Drag = pan.
Pinch = zoom.
Swipe drawer down = close.

Bottom navigation:
Realm / Armies / Diplomacy / More.
Build is contextual after District selection.

## Desktop
Central map with contextual side/lower drawer.

## Battle
Battlefield + Play/Pause + selected formation + Move/Attack/Hold/Retreat.

Seven main states:
Campaign Map, District Drawer, Army Drawer, Faction/Diplomacy Drawer, Event Window, Tactical Battle, Chronicle.
